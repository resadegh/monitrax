## Part A — the independent Ring-0 bracket walk

Rendered FY26-27 bracket table (read from `/dashboard/tax`):

| Income range | Rate | Tax on range |
|---|---|---|
| $0 – $18,200 | 0% | Nil |
| $18,201 – $45,000 | **15%** | 15c for each $1 over $18,200 |
| $45,001 – $135,000 | 30% | **$4,020** plus 30c for each $1 over $45,000 |
| $135,001 – $190,000 | 37% | **$31,020** plus 37c for each $1 over $135,000 |
| $190,001+ | 45% | **$51,370** plus 45c for each $1 over $190,000 |

**Base amounts re-derived from first principles — each must fall out of the band below it:**

| Base | Derivation | Result | Rendered | |
|---|---|---|---|---|
| 30% band base | `0.15 × (45,000 − 18,200)` = `0.15 × 26,800` | **$4,020** | $4,020 | ✓ |
| 37% band base | `4,020 + 0.30 × (135,000 − 45,000)` = `4,020 + 27,000` | **$31,020** | $31,020 | ✓ |
| 45% band base | `31,020 + 0.37 × (190,000 − 135,000)` = `31,020 + 20,350` | **$51,370** | $51,370 | ✓ |

The table is internally consistent: no base amount was typed, each one re-derives.

**Tax on the live taxable income of $145,426** (which sits in the 37% band):

```
FY26-27:  31,020 + 0.37 × (145,426 − 135,000) = 31,020 + 3,857.62 = $34,877.62  → renders $34,878
FY25-26:  31,288 + 0.37 × (145,426 − 135,000) = 31,288 + 3,857.62 = $35,145.62  → renders $35,146
          (FY25-26 bases: 0.16 × 26,800 = 4,288; 4,288 + 27,000 = 31,288)
Movement: 35,145.62 − 34,877.62 = $268.00 exactly = 26,800 × 1%
```

The movement **is** the legislated 16% → 15% cut applied to the full $18,201–$45,000 band, and lands as a flat −$268 for every taxable income at or above $45,000. Nothing about the taxpayer's own figures changed.
