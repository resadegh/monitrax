**Fix (per Reza's ACTUALS-FIRST decision):** `lib/services/loanCosts.ts` — THE transaction feed (linked repayments over the ONE trailing-12-month window → the canonical resolver), fed into `/api/loans` (attaches `resolvedCost`; expenses page + LoanDetailDialog read it), cashflow summary/intelligence, CFO scenarios run/context, AI debt-analysis, portfolio snapshot.
