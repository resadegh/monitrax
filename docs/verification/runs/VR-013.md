**Root cause (verified this session, §19.2):** the #1440-migrated surfaces called `resolveLoanMonthlyCost` with **no transactions** — same engine, different inputs (FIX_PROTOCOL §1 F2 class). The property path feeds linked repayments via `enrichPropertiesWithActuals` (trailing-12-month window) and reads $1,191; every other surface fell to the declared→floor path and read $1,271. The "no repayment set" caption keyed off `flooredToInterest`, which was true only because the feed was empty — the linked repayments (18 May / 18 Jun, prior FY but in-window) never reached the resolver. The resolver itself has no FY filter; the FY-scoped "Interest this FY" card is a separate labelled metric that feeds no cashflow figure.
