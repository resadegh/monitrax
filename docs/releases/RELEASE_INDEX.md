## Documentation Standards

1. All blueprints go in `blueprints/[feature-name].md`
2. All designs go in `designs/[feature-name].md`
3. Architecture decisions logged in `build-logs/ARCHITECTURE_LOG.md`
4. Release changelogs in `changelogs/[version].md`

## How to Use This Index

1. **Before starting work**: Check Active Development table
2. **Starting new feature**: Add entry to Active Development
3. **Completing feature**: Move to Completed Releases
4. **Looking for docs**: Use Feature Catalog links
