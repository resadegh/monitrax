# Changelog archive

> **Daily session detail.** Read these files when you need forensic detail about a specific session. For a month-level summary, read the monthly file (e.g. `../CHANGELOG_2026_04.md`).

This folder holds full per-session changelogs that have been **rolled up into a monthly summary** (per Tech Debt #4 — consolidation policy, 2026-05-19). The originals are preserved here so the operational record is never lost; only the top-level `docs/changelog/` index becomes scannable.

## Rule for future months

When a month accumulates **>5 daily changelog files** AND **the month is in the past**:
1. Build a `docs/changelog/CHANGELOG_YYYY_MM.md` summary with one paragraph per session pointing here for detail
2. Move the per-session files into this archive folder
3. Close Tech Debt #4 (or open a successor row if the pattern recurs)

The current month's dailies live in the parent `docs/changelog/` folder — the rule is "archive past months, keep current month live".
