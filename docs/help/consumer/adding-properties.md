# Properties page

`/dashboard/properties` is where every property you own appears as a tile. This article walks the page.

## How to get here

Sidebar → **My Wealth** → **Properties** (default tab).

## What's on the page

| Section | Where it is | What it shows |
|---|---|---|
| **Header** | Top | Page title + **+ Add property** button |
| **Property tiles** | Main grid | One tile per property. Tile shows address, value, LVR bar, equity, monthly cashflow (if investment) |
| **Filter chips** | Above grid | All / PPR (owner-occupied) / Investment |
| **Property detail dialog** | Click any tile | Tabs: Overview · Loans · Expenses · Strategy · Linked. Edit + Delete in the footer. |

## Common tasks

**To add a property:**
1. Click **+ Add property** at the top.
2. Fill the form: address, type (PPR / Investment), value, purchase price + date.
3. Link or create a loan.
4. For investments, add rental income.
5. Save → the tile appears on the page.

**To edit a property:**
1. Click the tile → detail dialog opens.
2. Click **Edit** in the dialog footer.
3. Change fields → Save.

**To link a loan to a property:**
1. Open the property → **Loans** tab.
2. Click **+ Link loan**.
3. Pick from existing loans or **Create new loan**.
4. Save.

**To mark a property as sold:**
1. Open the property → **Edit**.
2. Settings tab → toggle **Sold**.
3. Enter sale date + sale price.
4. Save → the property archives and stops contributing to live net worth.

**To add a property expense (insurance, council rates):**
1. Open the property → **Expenses** tab.
2. Click **+ Add expense**.
3. Fill the form → Save.
4. The expense flows into `/cashflow` automatically.

**To delete a property:**
1. Open the property → click **Delete** in the dialog footer.
2. Confirm in the two-step dialog.

## Common navigation questions

**Q: What do the tile metrics mean?**
Hover any metric label for a tooltip definition (LVR, equity, rental yield, etc.).

**Q: Why is my LVR bar red?**
LVR bars: green <60%, amber 60–80%, red >80% (the LMI threshold).

**Q: I want to put this property in a trust.**
Edit the property → change the **Owner entity** dropdown. Note: this is a Monitrax bookkeeping change. Real-world transfer triggers tax events — use **Ask a Professional** before acting.

**Q: How do I refresh the estimated value?**
Open the property → **Edit** → update the **Estimated value** field → Save. (Automated valuation updates queued for a future release.)

**Q: How do I see all my loans (not just per-property)?**
Sidebar → **My Accounts** → **Balances** → Loans group.
